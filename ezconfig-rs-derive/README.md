# ezconfig-rs-derive

> Procedural macro for [ezconfig-rs](https://crates.io/crates/ezconfig-rs).

This crate is an implementation detail of `ezconfig-rs` and is not meant to be used directly.

## Usage

Use `ezconfig-rs` instead:

```toml
[dependencies]
ezconfig-rs = "0.1"
serde = { version = "1", features = ["derive"] }
```
